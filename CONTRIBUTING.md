# Contributing to ParityPrint

Small, reviewable contributions welcome.

1. Create a focused issue or explain the change in a pull request.
2. Keep the standard-library-only runtime and privacy boundary intact.
3. Add or update tests before changing behavior.
4. Run the full local checks from the README.
5. Include a short note about values, paths, process execution, and network
   behavior for changes touching input or output.

Do not include real credentials, private environment snapshots, or personal
paths in issues, tests, examples, or commits.
